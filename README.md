# 獵豹 × 文城｜家長說明會

48 頁互動式動態簡報，保留直式海報原比例、出場動畫與可拖曳的播放進度。

[線上簡報](https://liyunwg.github.io/cheetah-wencheng-talk-20261030/index.html#A-01) · [場景總覽](https://liyunwg.github.io/cheetah-wencheng-talk-20261030/overview.html)

## 操作

- F：全螢幕；Esc：退出。
- ←／→：上一頁、下一頁；G：章節目錄。
- Space：播放或暫停；底部拉桿可調整動畫進度。
- 點海報可放大查看原圖。

## 本機預覽

本專案為純 HTML、CSS、JavaScript 靜態網站，無需安裝套件或編譯。使用任意靜態 HTTP 伺服器開啟本目錄即可。
